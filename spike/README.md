# spike/

설계를 정하기 전에 가정을 확인하려고 짠 일회성 코드. 제품 코드에서 가져다 쓰지 않는다.

| 폴더         | 확인한 것                                                           | 결과                                                                      |
| ------------ | ------------------------------------------------------------------- | ------------------------------------------------------------------------- |
| `downloads/` | Chrome 다운로드 이벤트에서 출처 URL·referrer·활성 탭을 얻을 수 있나 | 얻을 수 있음. macOS 메타데이터(quarantine, WhereFroms)엔 출처가 남지 않음 |

로그를 커밋할 때는 URL의 `?` 뒤를 가린다. 학번(`user_id`)이 들어 있을 수 있다.

# 스파이크 #3: 남은 가정 확인

LMS에서 PDF를 받을 때마다 앱 화면에 가정 다섯 개의 결과가 한 카드로 뜬다.

| 가정 | 확인 방법                                                                  | 판정                      |
| ---- | -------------------------------------------------------------------------- | ------------------------- |
| 1    | 다운로드가 시작될 때 활성 탭 URL의 `courses/<ID>`                          | 자동                      |
| 2    | 같은 이름의 파일을 전에 받았을 때와 `content_id` 비교                      | 자동 (다시 받아야 비교됨) |
| 3    | 같은 이름의 파일을 전에 받았을 때와 SHA-256 비교                           | 자동 (다시 받아야 비교됨) |
| 4    | 앱이 다운로드 폴더의 파일을 직접 읽음                                      | 자동                      |
| 5    | 확장이 LMS(Canvas)에 과목명과 주차(모듈)를 조회, PDF 첫 페이지도 함께 표시 | 자동                      |

과목명은 `/api/v1/courses/<ID>`의 `name`에서 학기·학수번호 접두어를 뗀 값, 주차는 `/modules?include[]=items`에서 받은 파일이 들어 있는 모듈이다. 짝짓기는 자료 뷰어 탭의 모듈 항목 번호(`modules/items/<번호>`)로 먼저 하고, 없으면 항목 제목 = 파일 이름으로 한다. 모듈 항목의 `content_id`는 LMS 도구 번호(모든 자료가 같은 값)라 짝짓기에 쓸 수 없다. 응답의 사용자·수강 정보는 쓰지도 넘기지도 않는다.

받을 때마다 `~/Library/Application Support/Sorted/probe-history.jsonl`에 파일 이름, `content_id`, 해시, 과목 ID를 남긴다. 경로와 URL은 남기지 않는다. 확장은 앱에 보내기 전에 URL의 쿼리를 모두 지운다 (학번 포함 가능).

## 확인 순서

가정 4는 반드시 **빌드한 앱**으로 확인한다. `npm run tauri dev`는 터미널에서 실행되므로 macOS가 터미널의 권한을 빌려 줘서, 실제 사용자 환경과 결과가 다르다.

```sh
cd ~/sorted && git pull && ./scripts/install-native-host.sh
cd app && npm install && npm run tauri build -- --bundles app
open target/release/bundle/macos/Sorted.app
```

1. `chrome://extensions`에서 Sorted의 새로고침 버튼을 누른다 (권한이 늘어 확인 창이 뜰 수 있음).
2. LMS 과목 페이지에서 강의자료 PDF를 받는다. 가능하면 서로 다른 과목에서 2~3개.
3. 처음 받을 때 "다운로드 폴더 접근" 권한 창이 뜨면 허용한다. 뜨지 않거나 거부했을 때 결과도 기록한다.
4. 앱 창의 카드에서 1·4·5를 확인한다.
5. **다음 날** 같은 파일을 다시 받아 2·3을 확인한다.

## 결과

2026-10-03, 소프트웨어공학(과목 ID 210208)의 1주차·2주차 자료로 확인. 같은 날 같은 자료를 한 번씩 더 받음.

| 가정 | 결과                   | 메모                                                                                                 |
| ---- | ---------------------- | ---------------------------------------------------------------------------------------------------- |
| 1    | 맞음                   | referrer와 활성 탭 모두 `courses/210208`. 탭은 자료 뷰어(`modules/items/<번호>`)                     |
| 2    | 맞음 (같은 날)         | 같은 자료를 다시 받아도 같은 값. 자료마다 다름 (`6a913a6546923`, `6a913aaa640aa`). 다른 날 확인 남음 |
| 3    | 맞음 (같은 날)         | LMS가 다운로드마다 파일을 바꾸지 않음 (워터마크 없음). 다른 날 확인 남음                             |
| 4    | 맞음                   | 빌드한 앱에서 처음 받을 때 다운로드 폴더 권한 창이 뜨고, 허용 후 2.1MB·427KB PDF를 직접 읽음         |
| 5    | 맞음 (LMS 조회로 바꿈) | 탭 제목은 파일 이름이라 쓸 수 없음. LMS API로 `소프트웨어공학 · 2주차`, 모듈 항목 번호로 짝지음      |

**설계에 반영할 것**

- FR-11: 과목명은 활성 탭 제목이 아니라 LMS의 과목 정보(`/api/v1/courses/<ID>`)에서 가져온다.
- FR-12: 주차는 LMS 모듈(`/modules?include[]=items`)에서, 자료 뷰어의 모듈 항목 번호로 짝짓는다. 없으면 제목 = 파일 이름.
- FR-3: `content_id`는 자료마다 고유하고 다시 받아도 같으므로 문서를 묶는 기준으로 쓴다.
- FR-15: 첫 다운로드 때 macOS 권한 창이 뜬다 (Info.plist 설명 문구 사용). 거부했을 때의 [설정 열기] 안내가 필요하다.
- PDF 첫 페이지는 과목 코드·강의 번호까지만 보여 준다 (주차 없음). 마지막 대체 수단으로만 쓴다.
